# TCP vs UDP  

### TCP ( Default , Reliable )  


- Connection oriented 
- Reliable delivery
- Guaranteed Ordering 
- Higher Latency 
- Flow Control , congestion Control 

###  UDP 

- Connectionless
- No Delivery Guarantee
- No Ordering 
- Lower Latency  
- usefull for relatime application and lossy application  
- used where where latency is  paramount and you can handle packet loss
